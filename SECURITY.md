# Security Policy

## Scope

This repository contains documentation and a static website. Relevant security issues
include:

- Vulnerabilities in the build or deployment workflows (for example, unsafe GitHub Actions
  configuration).
- Accidentally published secrets, credentials, or private information.
- Documentation that recommends an **insecure** configuration or would cause harm if
  followed.
- Malicious or compromised links in the documentation.

Vulnerabilities in third-party tools described here should be reported to those tools'
maintainers, not to this project.

## Reporting a vulnerability

Please report privately using GitHub's
[private vulnerability reporting](https://github.com/RiotPhoenix/cybersecurity-knowledge-base/security/advisories/new)
(*Security* tab → *Report a vulnerability*). Do **not** open a public issue for security
problems.

Include a description, affected files or URLs, and steps to reproduce. If you have found an
exposed secret, describe its location but do not repeat the secret value.

## Response

This is a volunteer-maintained project. We aim to acknowledge reports within 7 days and to
remediate confirmed issues as quickly as practical. Reporters are credited unless they
prefer otherwise.

## Inaccurate but non-dangerous content

For ordinary errors or outdated information, open a **Content correction** issue instead.
