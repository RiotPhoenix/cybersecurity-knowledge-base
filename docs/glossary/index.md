# Glossary

Core terms used throughout the knowledge base. Additional terms are added alongside the
entries that use them.

Attack surface
:   The set of points where an unauthorised user could try to enter data into, or extract data
    from, a system.

CVE (Common Vulnerabilities and Exposures)
:   A public catalogue of identifiers for disclosed vulnerabilities. Each identifier
    (for example `CVE-YYYY-NNNN`) refers to one specific vulnerability.

CVSS (Common Vulnerability Scoring System)
:   An open standard for rating the technical severity of vulnerabilities on a 0–10 scale.

DAST (Dynamic Application Security Testing)
:   Testing a running application from the outside by sending it requests, as a web scanner
    such as ZAP does, rather than analysing its source code.

EDR (Endpoint Detection and Response)
:   Tools that record endpoint activity, detect suspicious behaviour, and support investigation
    and response on hosts.

Hardening
:   Reducing a system's attack surface by removing unnecessary functionality and applying secure
    configuration.

IOC (Indicator of Compromise)
:   An observable artefact — such as a file hash, domain, or IP address — associated with
    malicious activity.

IPS (Intrusion Prevention System)
:   A system placed in the traffic path that can block traffic matching detection rules. Unlike
    a passive IDS, a failure or a bad rule can interrupt legitimate traffic.

Least privilege
:   Granting users and processes only the access they need to perform their function.

MFA (Multi-Factor Authentication)
:   Authentication that requires two or more independent factors — something you know, have,
    or are.

NIDS (Network Intrusion Detection System)
:   A system that monitors network traffic for signs of malicious activity or policy violations.

NSM (Network Security Monitoring)
:   Collecting and analysing records of network activity (connections, protocol transactions,
    alerts) to detect and investigate intrusions.

OSINT (Open-Source Intelligence)
:   Intelligence derived from publicly available information.

Penetration test
:   An authorised, scoped simulation of an attack to evaluate the security of a system.

Port mirroring (SPAN)
:   A switch feature that copies traffic from selected ports or VLANs to a monitoring port, so a
    passive sensor can observe it.

SBOM (Software Bill of Materials)
:   A formal inventory of the components and dependencies that make up a piece of software.

SIEM (Security Information and Event Management)
:   A platform that aggregates and correlates security-relevant logs and events to support
    detection, investigation, and compliance.

SOC (Security Operations Centre)
:   The team and function responsible for continuous security monitoring and response.

TAP (Test Access Point)
:   A device inserted into a network link that copies the traffic in both directions to
    monitoring ports.

Threat intelligence
:   Evidence-based knowledge about threats that informs security decisions.

Unsealing
:   In secrets managers such as OpenBao, supplying enough key shares (or using an automatic
    unseal key) to let the server decrypt its stored data after it starts.
