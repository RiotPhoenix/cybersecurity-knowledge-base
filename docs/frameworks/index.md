# Frameworks

Mappings between tools in this knowledge base and widely used security frameworks, to help
readers understand which controls or techniques a tool supports.

!!! note "Planned"
    Framework mappings have not been published yet.

Frameworks under consideration include:

| Framework | Publisher | Typical use |
|---|---|---|
| Cybersecurity Framework (CSF) | NIST | Organising security outcomes into functions |
| ATT&CK | MITRE | Describing adversary tactics and techniques |
| CIS Critical Security Controls | Center for Internet Security | Prioritised defensive safeguards |
| ISO/IEC 27001 | ISO/IEC | Information security management systems |

Mappings will link to the official framework publications and state the framework version used.
