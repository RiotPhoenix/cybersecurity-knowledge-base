# Getting Started

## How the knowledge base is organised

- **[Tools](../tools/index.md)** — the catalogue, grouped into fourteen categories by the
  security problem each tool addresses.
- **[Environments](../environments/index.md)** — guidance framed for personal/home-lab and
  enterprise contexts. Every tool entry rates its suitability for both.
- **[Guides](../guides/index.md)** — task-oriented walkthroughs that span several tools *(planned)*.
- **[Comparisons](../comparisons/index.md)** — side-by-side evaluations *(planned)*.
- **[Frameworks](../frameworks/index.md)** — mapping tools to recognised security frameworks *(planned)*.
- **[Glossary](../glossary/index.md)** — definitions of common terms.

## Reading a tool entry

Every tool entry follows the same [template](../contributing/tool-template.md), so you can
compare tools section by section. Before relying on an entry, check three fields at the top:

1. **Verification status** — how thoroughly the content has been checked. See
   [verification statuses](../contributing/verification-statuses.md).
2. **Tested versions** — the exact versions any instructions were validated against.
3. **Last reviewed** — when the entry was last checked against official sources.

!!! warning "Always confirm against official documentation"
    Tools change quickly. Treat this knowledge base as a starting point and confirm
    commands, versions, and security guidance against each tool's official documentation,
    which every entry links to.

## Searching

Use the **Search** button in the navigation bar, or press <kbd>s</kbd>. Press
<kbd>?</kbd> for keyboard shortcuts, <kbd>n</kbd> / <kbd>p</kbd> for next and previous page.
