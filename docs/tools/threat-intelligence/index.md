# Threat Intelligence

Tools for collecting, enriching, sharing, and operationalising information about threats.

## Purpose of this category

This category groups tools by the security problem they address, so readers can find
options for a given need and compare them consistently. Each tool entry follows the
[tool entry template](../../contributing/tool-template.md) and carries an explicit
[verification status](../../contributing/verification-statuses.md).

## Intended coverage

- Threat-intelligence platforms
- Indicator enrichment
- Intelligence-sharing standards and formats
- Mapping to adversary-behaviour frameworks
- Feed curation and quality assessment

## Environment considerations

| Environment | Typical focus |
|---|---|
| [Personal / home lab](../../environments/personal/index.md) | Following reputable public advisories and using free enrichment services responsibly. |
| [Enterprise](../../environments/enterprise/index.md) | Intelligence requirements, platform deployment, sharing communities, and feeding detections and blocking controls. |
