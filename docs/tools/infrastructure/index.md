# Infrastructure and Home Labs

Foundational infrastructure for building, isolating, and operating security labs and secure environments.

## Purpose of this category

This category groups tools by the security problem they address, so readers can find
options for a given need and compare them consistently. Each tool entry follows the
[tool entry template](../../contributing/tool-template.md) and carries an explicit
[verification status](../../contributing/verification-statuses.md).

## Intended coverage

- Virtualisation and hypervisors
- Containers for lab services
- Network segmentation and VLANs
- Lab architectures for safe testing
- Backup and recovery
- Monitoring the lab itself

## Environment considerations

| Environment | Typical focus |
|---|---|
| [Personal / home lab](../../environments/personal/index.md) | Building an isolated home lab for learning and safely testing tools. |
| [Enterprise](../../environments/enterprise/index.md) | Reference architectures, test environments that mirror production, and infrastructure hardening baselines. |
