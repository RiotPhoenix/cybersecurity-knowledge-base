# Identity and Access Management

Tools that manage digital identities, authentication, authorisation, and access governance.

## Purpose of this category

This category groups tools by the security problem they address, so readers can find
options for a given need and compare them consistently. Each tool entry follows the
[tool entry template](../../contributing/tool-template.md) and carries an explicit
[verification status](../../contributing/verification-statuses.md).

## Intended coverage

- Identity providers and single sign-on
- Multi-factor authentication
- Directory services
- Privileged access management
- Access reviews and governance
- Federation standards

## Environment considerations

| Environment | Typical focus |
|---|---|
| [Personal / home lab](../../environments/personal/index.md) | Strong authentication and MFA for personal accounts; SSO for a home lab. |
| [Enterprise](../../environments/enterprise/index.md) | Identity lifecycle, least privilege, privileged access, conditional access, and audit evidence. |
