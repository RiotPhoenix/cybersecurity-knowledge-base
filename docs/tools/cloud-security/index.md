# Cloud Security

Tools that assess and protect workloads, identities, and configurations in public and private clouds.

## Purpose of this category

This category groups tools by the security problem they address, so readers can find
options for a given need and compare them consistently. Each tool entry follows the
[tool entry template](../../contributing/tool-template.md) and carries an explicit
[verification status](../../contributing/verification-statuses.md).

## Intended coverage

- Cloud security posture management
- Infrastructure-as-code scanning
- Cloud identity and permission analysis
- Container and Kubernetes security
- Cloud-native logging and detection
- Secrets and key management services

## Environment considerations

| Environment | Typical focus |
|---|---|
| [Personal / home lab](../../environments/personal/index.md) | Securing personal cloud accounts and free-tier lab environments. |
| [Enterprise](../../environments/enterprise/index.md) | Multi-account governance, guardrails, continuous posture assessment, and shared-responsibility boundaries. |
