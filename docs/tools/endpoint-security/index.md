# Endpoint Security

Tools that protect, monitor, and harden individual workstations, servers, and mobile devices.

## Purpose of this category

This category groups tools by the security problem they address, so readers can find
options for a given need and compare them consistently. Each tool entry follows the
[tool entry template](../../contributing/tool-template.md) and carries an explicit
[verification status](../../contributing/verification-statuses.md).

## Intended coverage

- Anti-malware and EDR/XDR
- Host-based firewalls
- Host intrusion detection and file-integrity monitoring
- Application allow-listing
- Disk encryption
- System hardening and configuration baselines

## Environment considerations

| Environment | Typical focus |
|---|---|
| [Personal / home lab](../../environments/personal/index.md) | Hardening personal Linux, Windows, and macOS machines. |
| [Enterprise](../../environments/enterprise/index.md) | Fleet-wide agent deployment, policy management, telemetry routing to SIEM, and response automation. |
