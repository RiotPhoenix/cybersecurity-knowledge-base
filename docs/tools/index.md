# Tool Catalogue

Tools are grouped by the security problem they primarily address. A tool that spans several
areas is documented once, in its primary category, and cross-referenced from others.

| Category | Primary question it answers |
|---|---|
| [Network Security](network-security/index.md) | What is happening on my network, and how do I control it? |
| [Vulnerability Management](vulnerability-management/index.md) | What weaknesses exist, and which matter most? |
| [Penetration Testing](penetration-testing/index.md) | Do my controls hold up against realistic, authorised attack techniques? |
| [Digital Forensics](digital-forensics/index.md) | What happened, and can I prove it? |
| [OSINT](osint/index.md) | What can be learned from public sources? |
| [SIEM and Log Management](siem/index.md) | Can I see, search, and alert on security events? |
| [Endpoint Security](endpoint-security/index.md) | Are individual devices hardened and monitored? |
| [Incident Response](incident-response/index.md) | How do I respond when something goes wrong? |
| [Threat Intelligence](threat-intelligence/index.md) | Who and what threatens me, and how do I act on it? |
| [Cloud Security](cloud-security/index.md) | Are my cloud resources configured and governed securely? |
| [DevSecOps](devsecops/index.md) | Is security built into how software is built and shipped? |
| [Identity and Access Management](identity-access/index.md) | Is the right person getting the right access? |
| [Password and Secret Management](password-management/index.md) | Are credentials and secrets stored and rotated safely? |
| [Infrastructure and Home Labs](infrastructure/index.md) | Where can I build and test safely? |
