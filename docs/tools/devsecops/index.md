# DevSecOps

Tools that integrate security into software development and delivery pipelines.

## Purpose of this category

This category groups tools by the security problem they address, so readers can find
options for a given need and compare them consistently. Each tool entry follows the
[tool entry template](../../contributing/tool-template.md) and carries an explicit
[verification status](../../contributing/verification-statuses.md).

## Intended coverage

- Static application security testing (SAST)
- Dependency and supply-chain analysis
- Secret scanning
- Container image scanning
- Software bills of materials (SBOMs)
- CI/CD pipeline hardening

## Environment considerations

| Environment | Typical focus |
|---|---|
| [Personal / home lab](../../environments/personal/index.md) | Adding security checks to personal projects and repositories. |
| [Enterprise](../../environments/enterprise/index.md) | Pipeline policy enforcement, developer experience, triage at scale, and supply-chain integrity controls. |
