# Digital Forensics

Tools for acquiring, preserving, and analysing digital evidence in a defensible manner.

## Purpose of this category

This category groups tools by the security problem they address, so readers can find
options for a given need and compare them consistently. Each tool entry follows the
[tool entry template](../../contributing/tool-template.md) and carries an explicit
[verification status](../../contributing/verification-statuses.md).

## Intended coverage

- Disk and memory acquisition
- Forensic imaging and integrity verification
- File-system and artefact analysis
- Memory forensics
- Timeline construction
- Mobile and cloud artefact analysis
- Chain-of-custody documentation

## Environment considerations

| Environment | Typical focus |
|---|---|
| [Personal / home lab](../../environments/personal/index.md) | Learning forensic workflows on your own devices and practice images. |
| [Enterprise](../../environments/enterprise/index.md) | Legally defensible acquisition, evidence retention policies, and coordination with legal and HR functions. |
