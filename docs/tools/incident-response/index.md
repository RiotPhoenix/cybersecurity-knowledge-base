# Incident Response

Tools and processes that support detecting, containing, eradicating, and recovering from security incidents.

## Purpose of this category

This category groups tools by the security problem they address, so readers can find
options for a given need and compare them consistently. Each tool entry follows the
[tool entry template](../../contributing/tool-template.md) and carries an explicit
[verification status](../../contributing/verification-statuses.md).

## Intended coverage

- Triage and live-response collection
- Case management
- Playbooks and runbooks
- Containment and isolation tooling
- Communication and coordination
- Post-incident review

## Environment considerations

| Environment | Typical focus |
|---|---|
| [Personal / home lab](../../environments/personal/index.md) | Preparing a personal response plan for account compromise or malware infection. |
| [Enterprise](../../environments/enterprise/index.md) | IR plans aligned to recognised frameworks, on-call rotations, tooling for scale, and regulatory notification considerations. |
